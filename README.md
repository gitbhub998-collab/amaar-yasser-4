# Personal Portfolio

A static portfolio built with HTML, CSS, and JavaScript. It has no dependencies or build step.

## Project files

- `index.html` contains the page content.
- `styles.css` contains the responsive styles.
- `script.js` contains the page interactions.
- `assets/` contains profile and project images.
- `favicon.svg` contains the AY site icon.

## Publish with GitHub Pages

Push the project to a GitHub repository, then open **Settings > Pages**. Select **Deploy from a branch**, choose the `main` branch and `/ (root)`, and save. GitHub Pages will serve `index.html` and its local assets.

## Publish with Vercel

Import the repository into Vercel and use the **Other** framework preset. Leave the build command empty and set the output directory to `.`. The included `vercel.json` provides the static-site configuration.
